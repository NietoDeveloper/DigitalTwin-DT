# Media for the Examples section

Drop your files here. Missing files render a clean "coming soon" frame, so nothing breaks.

| File | Used by |
|---|---|
| `apartment.jpg` / `apartment.mp4` | Apartment (≈ 50 photos + 1 min video) |
| `warehouse.jpg` / `warehouse.mp4` | Warehouse fit-out |
| `building.jpg` / `building.mp4` | Whole building |
| `object.jpg` / `object.mp4` | Small object |

Tips: photos 1600 px wide, `.jpg` under 300 KB; videos H.264 `.mp4`, 720p, under 15 MB.
Only add media you own the rights to. To add more examples, edit `packages/content/src/data.ts`.
